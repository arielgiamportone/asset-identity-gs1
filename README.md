# asset-identity-gs1

GS1 identity for physical inventory assets: GIAI, GIAI-96 EPC, GS1 Digital Link,
checked aliases, Code128/QR label sheets and RFID ZPL, with offline multi-tenant
uniqueness. Clean-room case study.

> library and its synthetic test suite are complete.
